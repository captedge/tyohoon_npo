# devlog: ズーム時のオブジェクト・線描画の調整（2026-08-03）

## 背景

地図をズームすると、船・台風のアイコンやラベル、航路・軌跡の線までエリアに対して大きくなりすぎる、という指摘から始まり、同じ「ズーム時の見た目」というテーマで3回のやり取りが続いた。

1. 通過済み/予定針路の実線・点線分割 ＋ アイコン・ラベルをズームしても画面上で一定サイズに固定
2. 実線・点線の「太さ」も画面上で一定に固定、かつ船と台風で太さを統一
3. 点線の「長さ・間隔」のパターンも船と台風で統一（船の従来値より少し細かく）

## 試行錯誤の経緯

- 1回目で対応した範囲は「点や図形（アイコン・ラベル・WPの丸マーカー）」のみで、線の太さ・点線パターンは対象外だった（`Paint.strokeWidth`は`canvas.scale`の外で固定値のまま）。
- 2回目で線の太さも対象に含める指摘を受け、`canvas.scale(1/zoom)`で丸ごと縮小するアイコン方式ではなく、線は始点終点がシーン座標のまま（ズーム/パンに追従する必要があるため）、`strokeWidth`の値だけを「画面上で見せたい太さ×(1/zoom)」に計算する方式で対応。ついでに船（1.5）と台風（2）で別々だった太さを2.0に統一。
- 3回目で点線の長さ・間隔（`dashLength`/`gapLength`）も同様に船（4/3）と台風（デフォルト6/4、個別調整されていなかった）で揃っていないことが判明し、`_trackDashLengthPx`/`_trackGapLengthPx`という共有定数に切り出して統一。

## 次回同じ状況で使える判断基準（教訓）

**「ズームしても見た目を固定にしたい」という要望が来たら、対象を「アイコン・ラベル」だけに限定せず、最初に描画要素を洗い出してから一括対応する。** 具体的には、地図上の視覚要素は次の4種類に分類でき、それぞれ別の対応が要る：

1. 点状のオブジェクト（アイコン・マーカー）→ `canvas.translate`+`canvas.scale(1/zoom)`で図形ごと固定
2. テキストラベル → 1と同じ扱い（アイコンとセットで固定）
3. 線の太さ（`Paint.strokeWidth`）→ 線の始点終点はシーン座標のまま、太さの値だけ`×(1/zoom)`
4. 点線のパターン（長さ・間隔）→ 3と同じく値だけ`×(1/zoom)`（今回は「船と台風で統一」の指摘のみで、今のところズーム固定はしていない — 必要になれば同じ考え方で対応可能）

初回の要望確認時に「アイコン・ラベルだけでなく、線の太さや点線パターンも含めますか」と一括で確認できれば、今回のような3往復を1往復に圧縮できた可能性がある。ただし、これは「実物を見ないと気づきにくい調整」（宣言1の3秒チェックでいう②の後者）に近い面もあり、完全に往復ゼロにできたとは限らない。
